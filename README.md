# Полка

Личная коллекция фильмов, сериалов и книг. Статический сайт на HTML/CSS/JavaScript и Python CLI без внешних зависимостей. Добавление и изменение статусов происходит через CLI; сайт читает JSON-каталоги.

## Добавление

Запустите CLI без аргументов, чтобы добавить произведение по шагам:

```sh
python3 shelf.py
# То же самое:
python3 shelf.py add
```

CLI спросит тип (`1` — фильм, `2` — сериал, `3` — книга), русское и оригинальное названия, год и статус (`1` — в ожидании, `2` — просмотрено или прочитано). Статус по умолчанию — «В ожидании». Одно из названий можно пропустить клавишей Enter, но хотя бы одно должно быть заполнено.

Для книги после названий CLI спросит имя автора на русском и в оригинале, затем — год и статус. Оба имени можно пропустить клавишей Enter; у фильмов и сериалов этих полей нет.

Можно передать данные командой без вопросов:

```sh
# Достаточно одного названия.
python3 shelf.py add movie --title-ru "Куб" --year 1997
python3 shelf.py add book --title-original "Dune" --year 1965

# Можно указать оба названия и статус.
python3 shelf.py add movie --title-ru "Начало" --title-original "Inception" --year 2010 --status watched

# Сериал. Год — год премьеры сериала.
python3 shelf.py add series --title-ru "Твин Пикс" --title-original "Twin Peaks" --year 1990 --status watched

# Книга. Год — год первой публикации.
python3 shelf.py add book --title-ru "Дюна" --title-original "Dune" --author-ru "Фрэнк Герберт" --author-original "Frank Herbert" --year 1965 --status read
```

Пропущенное название сохраняется в JSON как пустая строка. Дата добавления назначается автоматически. Записи не содержат отдельного ID: для выбора произведения используются тип, название и год.

Для книг доступны параметры `--author-ru` и `--author-original`, которые сохраняются в поля `author_ru` и `author_original`. Пропущенные имена сохраняются как пустые строки. Прежний `--author` остаётся алиасом `--author-ru`. На сайте оба имени отображаются под названием книги и учитываются в общем поиске. При миграции старое поле `author` переносится в `author_ru`, а `author_original` остаётся пустым.

## Статусы и просмотр списка

| Значение в CLI/JSON | На сайте | Типы |
| --- | --- | --- |
| `waiting` | В ожидании | Все |
| `watched` | Просмотрено | Фильмы и сериалы |
| `read` | Прочитано | Книги |

```sh
python3 shelf.py list
python3 shelf.py list --type book --status waiting
python3 shelf.py list --json

# --title ищет по русскому или оригинальному названию.
python3 shelf.py set-status movie watched --title "Куб" --year 1997

# Для поиска по конкретному полю используйте --title-ru или --title-original.
python3 shelf.py set-status book read --title-original "Dune" --year 1965
python3 shelf.py set-status series waiting --title-ru "Твин Пикс" --year 1990

python3 shelf.py --help
python3 shelf.py add --help
```

Для смены статуса обязателен один из параметров: `--title`, `--title-ru` или `--title-original`. Если название подходит нескольким записям, CLI попросит уточнить поле поиска и не изменит статусы.

У каждой записи одновременно хранятся два отдельных поля: дата добавления `added_at` и дата просмотра или прочтения `completed_at`. На сайте год и обе даты отображаются в отдельных столбцах. На узком экране таблица прокручивается по горизонтали. Смена статуса обновляет только дату завершения; дата добавления сохраняется. Даты хранятся в формате ISO 8601 со временем и часовым поясом и также выводятся командой `list`.

- При добавлении со статусом `watched` или `read` значение `completed_at` точно совпадает с `added_at`.
- Каждый вызов `set-status` со статусом `watched` или `read` ставит в `completed_at` текущее время, даже если статус не изменился. Дата добавления сохраняется.
- При статусе `waiting` значение `completed_at` равно `null`; возврат в ожидание очищает дату просмотра или прочтения.
- При миграции старых завершённых записей без `completed_at` начальным значением становится `added_at`.
