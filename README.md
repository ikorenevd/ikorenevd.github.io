# Полка

Личная коллекция фильмов, сериалов и книг. Статический сайт на HTML/CSS/JavaScript и Python CLI без внешних зависимостей. Добавление и изменение статусов происходит через CLI; сайт читает JSON-каталоги.

## Локальный просмотр

Требуется Python 3.9 или новее. Из корня проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8000. Открытие `index.html` через `file://` не подходит: браузер ограничивает загрузку JSON. Сервер останавливается сочетанием Ctrl+C.

## Добавление

```sh
# Фильм. Статус по умолчанию — в ожидании.
python3 shelf.py add movie --title-ru "Начало" --title-original "Inception" --year 2010

# Сериал. Год — год премьеры сериала.
python3 shelf.py add series --title-ru "Твин Пикс" --title-original "Twin Peaks" --year 1990 --status watched

# Книга. Год — год первой публикации.
python3 shelf.py add book --title-ru "Дюна" --title-original "Dune" --year 1965 --status read
```

Русское и оригинальное названия обязательны. Для русскоязычного произведения они могут совпадать. Дата добавления назначается автоматически. Записи не содержат отдельного ID: для выбора произведения используются тип, оригинальное название и год. Повторное добавление этого сочетания отклоняется.

## Статусы и просмотр списка

| Значение в CLI/JSON | На сайте | Типы |
| --- | --- | --- |
| `waiting` | В ожидании | Все |
| `watched` | Просмотрено | Фильмы и сериалы |
| `read` | Прочитано | Книги |

```sh
python3 shelf.py list
python3 shelf.py list --type book --status waiting
python3 shelf.py list --json

# Укажите тип, оригинальное название и год нужного произведения.
python3 shelf.py set-status movie watched --title-original "Inception" --year 2010
python3 shelf.py set-status book read --title-original "Dune" --year 1965
python3 shelf.py set-status series waiting --title-original "Twin Peaks" --year 1990

python3 shelf.py --help
python3 shelf.py add --help
```

После изменения каталога обновите страницу сайта. Статистика показывает выбранный тип медиа, а в разделе «Все» — всю коллекцию. Для фильмов и сериалов отображается «просмотрено», для книг — «прочитано». Фильтр статуса и поиск применяются только к списку. Записи упорядочены по дате добавления, сначала новые.

## Формат данных

```text
├── index.html
├── app.js
├── styles.css
├── shelf.py
└── src/
    └── data/
        ├── movies.json
        ├── series.json
        └── books.json
```

- `src/data/movies.json` — массив фильмов (`movie`).
- `src/data/series.json` — массив сериалов (`series`).
- `src/data/books.json` — массив книг (`book`).

Структура записи (пример):

```json
{
  "type": "movie",
  "title_ru": "Начало",
  "title_original": "Inception",
  "year": 2010,
  "status": "waiting",
  "added_at": "2026-09-11T20:00:00.000000+03:00"
}
```

`added_at` — дата и время ISO 8601 с часовым поясом. На сайте дата отображается в часовом поясе браузера. Для книги структура такая же, `type` — `book`, завершённый статус — `read`.

При смене статуса оригинальное название сравнивается без учёта регистра и пробелов по краям. Год позволяет различать одноимённые произведения.

CLI проверяет все три каталога перед изменениями, отклоняет некорректные данные, записывает файл атомарно и блокирует одновременную запись другим экземпляром CLI. Ручное редактирование JSON во время работы CLI не поддерживается.

По умолчанию каталог расположен в `src/data/` рядом со скриптом независимо от текущей директории. Для отдельной коллекции укажите глобальный параметр **перед** командой:

```sh
python3 shelf.py --data-dir /tmp/my-shelf add book --title-ru "Дюна" --title-original "Dune" --year 1965
python3 shelf.py --data-dir /tmp/my-shelf list
```

Сайт всегда читает `src/data/` в своём корне. Параметр `--data-dir` меняет только каталог CLI.

## GitHub Pages

Проект готов к размещению в репозитории `ikorenevd.github.io`: в настройках GitHub Pages выберите публикацию из ветки `main`, папки `/ (root)`. Сборка, Node.js и сервер Python на хостинге не нужны. Публикация из этой рабочей копии пока не выполнена.

Для обновления опубликованной коллекции добавьте записи локально через CLI, затем закоммитьте и отправьте изменённые файлы из `src/data/` в репозиторий. После завершения публикации GitHub Pages новые записи появятся на сайте. Каталоги опубликованного сайта доступны его посетителям.

## Проверка CLI

```sh
python3 -m unittest discover -s tests -v
```

Тесты используют временные каталоги и не меняют вашу коллекцию.
